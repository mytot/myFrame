Web Flasher beta

Plug your board via USB, pick the board, hit Connect, then Install. Uses Web Serial — Chrome / Edge on desktop. No driver on Linux/macOS; on Windows install CP210x / CH340 if needed.

1 · Select board

Supported boards →

2 · Pick version

Latest is pre-selected. Factory = full flash (use for first install). OTA = app only.

3 · Flash

Erase is optional — recommended for first install
Web Serial not supported — use Chrome/Edge desktop, or esptool. Connect permission denied — allow the serial prompt.
If flashing fails, hold BOOT and tap RST, then retry. Some 8048S070-C require USB power, not just 5V barrel.
Advanced: manual esptool 
esptool.py --chip esp32s3 --port /dev/ttyACM0 write-flash -z 0x0 myframe.factory.bin

Factory image includes bootloader + partition table + shell. OTA image is 0x20000 only.
