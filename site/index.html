Supported boards

Add a board by adding a folder under devices/. Same firmware, different pins.

Want your board? See Device Support.

Two app models

Native (full IDF, OTA slot, reboot) and Managed (WASM, hot-load ~10 ms). Same catalog, same signing, same store UI.

Signed everything

Ed25519 from day one. Root signs catalog, publishers sign packages. Dev-mode bypass is a build flag, not a default.

Render in SRAM

LVGL renders to 2× 800×16 SRAM lines, blits only the dirty rect to PSRAM. No beam-chasing, no tearing, 39 Hz measured.

Dev store included

tools/devstore.py serves catalog, packages, and a browser UI that proxies the device HTTP API. No cloud needed.

Quick start

# web flasher → https://mytot.github.io/myFrame/flasher/
# or esptool:
esptool.py --chip esp32s3 --port /dev/ttyACM0 write-flash -z 0x0 myframe.factory.bin
make                  # host tests (no IDF)
. $IDF_PATH/export.sh && idf.py build
python3 tools/devstore.py --pkgs dist --port 8080  # → device Settings → Store URL = http://laptop:8080
python3 tools/build_app.py examples/wasm_hello/app.c --manifest examples/wasm_hello/manifest.json --out dist/clock.fpack
python3 tools/pack.py --verify dist/clock.fpack --pubkey keys/dev/publisher.pub --device-code
python3 tools/catalog.py build --pkgs dist --out store --base-url http://192.168.1.10:8080
